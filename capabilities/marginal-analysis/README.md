# Marginal Analysis

This capability uses information from marginal analysis to compare growing tomatoes, carrots, and mesclun under shared constraints to determine the maximum-profit allocation for these crops.

## Engagements that used this capability

- [perfect-competition](../../docs/briefs/perfect-competition-brief.md) — farm bed allocation across tomatoes, carrots, and mesclun

### Stage 3 application

Used marginal analysis and Solver to evaluate marginal revenue versus marginal cost, shared labor allocation, binding and slack constraints, and additional-bed decisions. The analysis validated the 10 tomato / 20 carrot / 30 mesclun allocation as the maximum-profit farm plan.
